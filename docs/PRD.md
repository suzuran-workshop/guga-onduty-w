# PRD — 校园值周管理

## 产品目标
用数字化工具体替代传统纸质值周打分表，实现打分→统计→申诉→红旗颁发的全链路管理。
同时为校园信息化大屏提供实时数据源。

## 用户与使用场景
| 用户 | 角色 | 典型场景 |
|------|------|----------|
| 值周生 | duty_student | 巡查校园，在手机上选择班级→选标签→打分→拍照→提交 |
| 班主任 | teacher | 收到扣分通知，查看详情，发起申诉 |
| 德育主任/行政 | admin | 管理年级班级配置、审核申诉、生成周报、颁发流动红旗 |
| 来访者/校领导 | guest | 在大屏前查看实时排名和最新记录 |

## 核心问题
1. 纸质打分表易丢失、难汇总
2. 班主任对扣分的异议无规范处理流程
3. 多校区数据不互通，无法统一查看
4. 周排名手工计算费时且易错
5. 校园信息化展示缺少实时数据

## 功能及其意义
| 功能 | 解决什么 | 为什么需要 |
|------|----------|------------|
| 标签+积分实时记录 | 替代纸质打分表 | 结构化数据才能自动统计 |
| 自定义值周小组 | 值周安排灵活 | 不同学校/周次值周安排不同 |
| 自定义评价标签和分值 | 评分标准可配置 | 卫生/纪律/两操各校标准不同 |
| 标签模板 | 快速套用常用标签集 | 减少值周生操作步骤 |
| 文字+图片记录 | 提供扣分证据 | 有争议时可回溯 |
| 每日小结+教师通知 | 班主任及时了解 | 减少沟通滞后 |
| 多维度统计排名 | 自动计算周排名 | 替代手工排序 |
| 数据导出CSV | 存档和二次分析 | 对接学校报表系统 |
| 申诉流程 | 规范异议处理 | 避免扣分争议升级 |
| 流动红旗 | 班级激励 | 正向反馈机制 |
| 多校区管理 | 多校区数据隔离 | 各校区独立运行互不干扰 |
| 数字大屏 | 校园信息化展示 | 来访参观和家长会场景 |

## 功能之间的关系
```
配置(校区/年级/班级/标签/模板) → 值周记录(打分) → 统计(排名/趋势)
                                                     ├── 申诉(班主任→管理员)
                                                     ├── 流动红旗(自动评选)
                                                     ├── 每日小结(通知教师)
                                                     └── 数字大屏(实时展示)
```

## 范围与非目标
- **范围内**：值周打分、标签管理、统计排名、申诉机制、红旗颁发、多校区、大屏
- **范围外**：学生考勤、课表管理、家校通App、成绩管理
