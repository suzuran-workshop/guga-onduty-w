### 待改进
1. **通知推送**：数据模型已就绪（notified_teachers），但实际推送（WebSocket/短信/邮件）尚未实现
2. **@m3e/react 集成**：当前使用原生 CSS + 自定义组件，未深度使用 @m3e/react 的 Web Component 绑定（因其 API 为 Web Component 封装，与 React 范式需要适配层）
3. **图片查看**：上传已实现，但记录列表中的图片缩略图展示和点击放大需补充
4. **移动端适配**：响应式已做基础处理，移动端导航可改为底部 TabBar
